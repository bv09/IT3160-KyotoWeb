Here is a comprehensive summary of the Kyoto Transit Routing backend API:

Backend Architecture
App Factory (app.py)
Flask application with CORS enabled
Loads OSM data on startup into a SubwayGraph instance
Registers blueprints for API routes and serves static frontend files
Data file path configured via DATA_FILE env var
Configuration (config.py)
Three configs: Development (debug=True, port 5010), Production, Testing
Default: DevelopmentConfig
Data Models
SubwayGraph (models/subway_graph.py)
Core graph data structure with:

nodes: dict — {node_id: (lat, lon)} mapping
adj: dict — adjacency list {node_id: [(neighbor_id, distance), ...]}
stops: dict — {node_id: station_name} for named stations
blocked_nodes: set — set of blocked/disabled node IDs
entrances: dict — station entrance nodes
kd_tree — scipy KDTree for spatial nearest-neighbor lookup
node_list — ordered list of node IDs for KDTree indexing
Key methods:

add_node(node_id, lat, lon) / add_edge(u, v, dist)
add_stop(node_id, name) / add_entrance(node_id, name)
toggle_blocked(node_id) — toggles blocked status
is_blocked(node_id) — checks if blocked
unblock_all() — clears all blocked nodes
find_nearest(lat, lon) — finds nearest graph node using KDTree
build_kd_tree() — builds the spatial index
Services
DijkstraService (services/dijkstra.py)
find_shortest_path(graph, start_id, end_id) — Standard Dijkstra using min-heap
Returns (path: list[node_id], distance: float) or ([], float('inf')) if no path
Respects blocked nodes — skips neighbors that are in graph.blocked_nodes
OSMLoaderService (services/osm_loader.py)
load_from_file(filepath) → SubwayGraph
Parses raw OSM JSON data
Processes railway relations (type: route, route: train/subway/tram)
Extracts stops, platforms, entrances from relation members
Builds edges between consecutive way nodes using Haversine distance
Builds KDTree after loading
API Endpoints (routes/api.py)
GET /api/v1/map-data
Returns the complete graph for map rendering.

Response:

json


{
  "nodes": {"node_id": [lat, lon], ...},
  "edges": [[node_id_1, node_id_2], ...],
  "stops": {"node_id": "Station Name", ...},
  "blocked_nodes": ["node_id_1", ...]
}
POST /api/v1/pathfind
Finds shortest path between two coordinates.

Request:

json


{
  "start": [lat, lon],
  "end": [lat, lon]
}
Response (200):

json


{
  "path": [[[lat, lon], "Station Name or null"], ...],
  "distance_meters": 3456.78
}
Snaps start/end to nearest graph nodes using KDTree
Path entries are [[lat, lon], name_or_null] pairs
Returns 400 if start/end missing, 404 if no path found
POST /api/v1/toggle-node
Toggles a node's blocked status.

Request:

json


{
  "node_id": "12345"
}
Response (200):

json


{
  "node_id": "12345",
  "is_blocked": true
}
POST /api/v1/unblock-all
Unblocks all blocked nodes.

Response (200):

json


{
  "message": "All nodes unblocked"
}
Utilities
haversine.py
haversine(lat1, lon1, lat2, lon2) — Returns distance in meters between two coordinates
validators.py
validate_coordinates(data, field) — Validates lat/lon coordinate arrays in request data
Key Notes
Node IDs are strings (OSM node IDs as strings)
Stations are called "stops" in the backend — stops dict maps node_id → station name
The backend only computes ONE route (shortest distance via Dijkstra) — NOT two routes as the spec requests. The "Fastest Travel Time" route would need a different weight function or a separate endpoint.
No travel time calculation exists — only distance in meters is returned
The proxy is configured at localhost:5010 in vite.config.ts

lib/api.ts
typescript


const API_BASE = '/api/v1';
export async function fetchMapData() {
  const res = await fetch(`${API_BASE}/map-data`);
  if (!res.ok) throw new Error('Failed to fetch map data');
  return res.json();
}
export async function findRoute(start: [number, number], end: [number, number]) {
  const res = await fetch(`${API_BASE}/pathfind`, {
    method: 'POST', headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ start, end }),
  });
  if (!res.ok) { const err = await res.json().catch(() => ({})); throw new Error(err.error || 'Failed to find route'); }
  return res.json();
}
export async function toggleNode(nodeId: string) {
  const res = await fetch(`${API_BASE}/toggle-node`, {
    method: 'POST', headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ node_id: nodeId }),
  });
  if (!res.ok) throw new Error('Failed to toggle node');
  return res.json();
}
export async function unblockAll() {
  const res = await fetch(`${API_BASE}/unblock-all`, { method: 'POST' });
  if (!res.ok) throw new Error('Failed to unblock all');
  return res.json();
}
